# Visual Comparison: Old vs New

## OLD GAME (Calculation-Based)

```
┌─────────────────────────────────────────────────────────────┐
│  Mólmassi Leikur                                           │
│  Læra um mólmassa efna                                     │
└─────────────────────────────────────────────────────────────┘

┌──────────────────────────┬──────────────────────────────────┐
│                          │  Stats Bar                       │
│       H₂O                │  Stig: 30  Rétt: 2/3  Rað: 2 🔥  │
│       Vatn               │                                  │
│       [Auðvelt]          │                                  │
│                          ├──────────────────────────────────┤
│ Hver er mólmassi         │                                  │
│ efnisins? (g/mol)        │  Helper Buttons:                 │
│                          │  [📊 Lotukerfið]                 │
│ [___18.015___] [Svara]   │  [💡 Sýna útreikning (-5 stig)]  │
│                          │                                  │
│                          │  ← CHEAT BUTTON!                 │
└──────────────────────────┴──────────────────────────────────┘

STUDENT EXPERIENCE:
1. See "H₂O - Vatn"
2. Think: "I need to calculate..."
3. Click "📊 Lotukerfið"
4. Find: H = 1.008, O = 15.999
5. Calculate: 2×1.008 + 15.999 = 18.015
6. Type: "18.015"
7. Click "Svara"
8. OR: Click "Sýna útreikning" → See full solution → Copy answer

Time spent: 1-3 minutes per question
Understanding gained: Procedural only (can calculate, can't explain)
```

## Key Visual Differences

### OLD: Abstract Formula

```
      H₂O
      ↓
  Just text, no visual meaning
```

### NEW: Visual Molecules

```
      H₂O
      ↓
    ⚪ ⚪ 🔴
    H  H  O
    ↓
  "Oh! Two small atoms + one big atom"
```

## Interaction Comparison

### OLD Game Loop:

```
1. See formula (text)
2. Open periodic table
3. Find atomic masses
4. Do math on paper/calculator
5. Type number
6. Click submit
7. Hope for green checkmark
8. Time: 2-3 minutes
9. Understanding: "I memorized the process"
```

### NEW Game Loop:

```
1. See visual molecule
2. Engage with challenge (count/compare/build)
3. Make selection
4. Get immediate feedback
5. Read educational note
6. Move to next challenge
7. Time: 20-40 seconds
8. Understanding: "I know what molecules are made of"
```

## Atom Visual Key

```
Element    Color      Size    Represents
─────────────────────────────────────────
H          ⚪ White   Small   ~1 g/mol (lightest)
C          ⚫ Black   Medium  ~12 g/mol
N          🔵 Blue    Medium  ~14 g/mol
O          🔴 Red     Medium  ~16 g/mol
S          🟡 Yellow  Large   ~32 g/mol
Cl         🟢 Green   Large   ~35 g/mol
Na         🟣 Purple  Large   ~23 g/mol
Ca         🟠 Orange  Large   ~40 g/mol
```

**Key insight:** Size correlates with mass. Students intuitively learn "bigger circle = heavier atom" without memorizing numbers.

## Can Student Cheat?

### OLD Game:

| Method                               | Possible? |
| ------------------------------------ | --------- |
| Click "Sýna útreikning"              | ✅ YES    |
| Copy answer from friend              | ✅ YES    |
| Use calculator without understanding | ✅ YES    |
| **Pass without learning**            | ✅ YES    |

### NEW Game:

| Method                         | Possible?                   |
| ------------------------------ | --------------------------- |
| Show solution button           | ❌ NO (doesn't exist)       |
| Guess randomly                 | ⚠️ Harder (must understand) |
| Copy from friend               | ❌ NO (visual interaction)  |
| **Must understand to succeed** | ✅ YES                      |

## Mobile Experience

### OLD:

- Requires keyboard for number input
- Small touch targets
- Periodic table modal is cramped
- Calculator needed (external app)

### NEW:

- Large touch-friendly buttons
- No keyboard needed
- Visual atoms easy to tap
- Self-contained (no external tools)

---

## Learning Outcomes

### After OLD Game:

```
Student can: Calculate 2×1.008 + 15.999 = 18.015
Student cannot: Explain what H₂O means visually
```

### After NEW Game:

```
Student can: "H₂O has 2 hydrogen atoms and 1 oxygen atom"
Student can: "Oxygen is heavier than hydrogen"
Student can: "More atoms = more mass"
Student cannot: Calculate exact molar mass (that's Level 3)
```

## Progression Path

```
Level 1 (NEW)           Level 2                 Level 3 (OLD)
──────────────          ────────────            ─────────────
Visual atoms     →      Estimate mass    →      Calculate mass
Count atoms      →      Order by mass    →      Use formula
Compare sizes    →      Approximate      →      Exact numbers
Build molecules  →      Predict changes  →      Unit conversions

NO NUMBERS              ROUGH NUMBERS           EXACT NUMBERS
```

## Why This Matters

### Cognitive Load Theory

- Visual < Symbolic < Abstract
- Pictures are processed faster than text
- Spatial reasoning builds mathematical intuition

### Constructivism

- Students build knowledge through interaction
- Active manipulation > passive observation
- Mistakes are learning opportunities

### PhET Principles

- "Manipulate, observe, explain"
- Immediate feedback
- Multiple representations
- Low floor, high ceiling
